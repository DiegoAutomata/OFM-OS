# Leaderboard profile review log

This log captures manual, user-selected reviews of public leaderboard profiles.
It records transferable positioning and writing patterns rather than reproducing
profile text or treating a leaderboard rank as causal proof.

## June 2026 — Rank #1: Nyannie

### Observed profile signals

- A strongly established VTuber / goth / anime identity, with a very large
  audience and repeated historical first-place leaderboard badges.
- A compact profile description built from identity labels, a concrete visual
  cue, an intensity/relationship promise, a direct-message availability signal,
  and clear content-format coverage.
- Tier names are fantasy-led and audience-native rather than administrative.
- Recent post captions keep the same voice: short second-person hooks,
  questions, teasing, and recurring niche vocabulary.

### Transferable lessons

1. A bio should make the creator's distinct identity recognizable immediately;
   it should not begin as a generic sexual self-description.
2. Pair one grounded visual or character cue with a relationship promise so the
   reader understands both the fantasy and their role in it.
3. When truthful and relevant, state a concrete interaction or format promise
   to remove uncertainty about what the audience receives.
4. Keep bio voice, captions, tier naming, and visual niche coherent.

### Guardrails

- Do not import a VTuber/goth/anime angle, list format, or specific wording
  into profiles whose inputs do not support it.
- Rank is not causal proof: this creator also benefits from a mature brand,
  repeat placements, follower scale, and publishing consistency.
- For newer OFM-OS profiles, retain the concise micro-story structure. Add a
  compact interaction promise only when supported by the model's actual offer.
